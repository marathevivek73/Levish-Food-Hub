🍽️ Levish's Food Hub

Welcome to Levish's Food Hub!

Levish's Food Hub is a modern and attractive food ordering website where users can explore delicious food items, browse different categories, and discover special dishes. It provides a simple and user-friendly experience for food lovers.

🌟 Features

- 🏠 Attractive Home Page
- 🍕 Explore 20+ Delicious Dishes
- 🥗 Different Food Categories
- 🍔 Special Food Menu
- 📱 User-Friendly Design
- 📞 Contact Section
- 🎨 Attractive Food Images and Layout

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

2. Open the project folder.

4. Explore Levish's Food Hub!

The main objective of this project is to develop an attractive and user-friendly food website while improving practical skills in HTML, CSS, and JavaScript.
